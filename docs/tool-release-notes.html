Internal pipeline tools are versioned and documented here. All entries are listed newest first. For bug reports or feature requests, submit a Support Ticket.
Changelog
v2.3.1 LocalBurn 2025-03-14
Bug Fix

Fixed frame range override not applying on multi-machine Deadline Cloud submits. Affected batch renders with frame stepping enabled.

v1.8.0 Fast Cache 2025-02-28
New Feature

Added ACEScg → sRGB preview bake option for client review exports. Accessible via the Export menu in the Fast Cache panel.

v3.1.0 CompReview 2025-02-10
New Feature

ShotGrid version auto-link on publish. CompReview now queries the active SG context and links the published version automatically without manual entry.

v2.3.0 LocalBurn 2025-01-22
New Feature

Deadline Cloud worker pool selection added to submit UI. Artists can now target specific pools (e.g. gpu-pool, cpu-pool) from the LocalBurn panel.

v1.7.2 Fast Cache 2024-12-05
Bug Fix

Resolved NAS path resolution failure on Y: drive remount. Fast Cache now re-validates mount points on session startup.

v3.0.0 CompReview 2024-11-18
Breaking Change

Requires Nuke 16.0 or higher. Nuke 15 support has been dropped. Artists on Nuke 15 must upgrade before using CompReview v3.x.

Submit a Support Ticket for bug reports. Feature requests can be included in the ticket notes field.
