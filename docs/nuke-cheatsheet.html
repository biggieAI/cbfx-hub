CBFX Gizmos

Studio-built gizmos available in the toolbar under CBFX ›. Source lives in tk-config-cbfx v3.0.0. File a Support Ticket if a gizmo misbehaves — don't fork locally.

Read & Setup

CBFX_Read
Read wrapper that auto-resolves colorspace from filename + show OCIO config.
CBFX_ShotSetup
One-click frame range + format + colorspace from ShotGrid shot context.
CBFX_PlateLoader
Drops in main plate, latest matchmove, and reference EXRs in a labeled backdrop.

Comp Utilities

CBFX_Despill
Channel-isolated despill with edge protection. Replaces stock IBKColor for green/blue keys.
CBFX_EdgeBlend
Soft edge re-integration after key/roto. Premult-aware.
CBFX_LightWrap
Studio light-wrap recipe. Driven by BG light direction + intensity.
CBFX_Grain
Show-specific grain profiles. Picks the right plate match from the show config.
CBFX_LensDistort
Wrapper around LensDistortion with cached STMaps. ⌥+click to re-cache.

QC & Review

CBFX_QC
Edge / matte / black-level / alpha / NaN sanity strip. Drop near a Write to bake into review.
CBFX_Slate
Auto-slate from ShotGrid context: shot, version, frame, artist, date.
CBFX_ReviewBurnin
Timecode + frame counter + version stamp. Used for internal review only.
CBFX_NaNCheck
Flags NaN / Inf pixels. Mandatory on any render-bound branch.

Delivery

CBFX_Write
Write wrapper with the studio EXR settings (compression, bit depth, multichannel, ACES metadata).
CBFX_Deliver
End-of-comp delivery branch. Picks the right ODT + bake settings per delivery type.

If You Remember Nothing Else

  • Tab — node creation search. Live in it.
  • D — disable. Faster than re-routing pipes to debug.
  • F — fit. Works in Viewer and node graph. Constant use.
  • 1–9 — Viewer inputs. Slam between A/B comparisons with Tab.
  • E — keyframe at current frame. Animate without opening the curve editor.
  • Ctrl + Y — backdrop. Tag what you build so future-you doesn't curse present-you.
  • F8 — flipbook. Always flipbook before submitting; the Viewer lies about playback.
  • Always use CBFX_Write on delivery branches. Stock Write nodes will pass QC and then fail at studio QC.
