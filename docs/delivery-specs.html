Frame Handles

8
Frames — each side (default)

All VFX deliveries include 8 frames of handle on each side of the cut unless the client specifies otherwise. Always confirm handle requirements at show kickoff and document any exceptions in the show bible.

# Handle notation in filename (start–end frames inclusive of handles): # Shot cut: 1001–1100 | With 8-frame handles: 0993–1108 PROJ_010_0100_COMP_v001.0993.exr ← handle start ... PROJ_010_0100_COMP_v001.1001.exr ← cut in ... PROJ_010_0100_COMP_v001.1100.exr ← cut out ... PROJ_010_0100_COMP_v001.1108.exr ← handle end

Nuke Write node: set frame range to include handles. Never trim to cut points before receiving explicit sign-off from editorial.

Slate Requirements

All client deliveries must include a 1-second (24–25 frame) slate before the first handle frame. The slate must display the following information in a legible layout:

  • Show Name — full show title as agreed with client
  • Shot Code — in standard CBFX format (e.g. PROJ_010_0100)
  • Version — version string (e.g. v003)
  • Date — package date in YYYY-MM-DD format
  • Colorspace — the display colorspace baked into the delivery (e.g. Rec.709)
  • Artist Initials — 2–3 letter initials of the lead artist responsible for the delivery
  • Duration — total frame count including handles (e.g. 116 frames)

Use the approved CBFX slate template from Y:\_TOOLS\templates\cbfx_slate_v2.nk. Do not create ad-hoc slates.

Audio

VFX deliveries are MOS (no audio) by default. Do not mux audio into any VFX delivery file under any circumstances.

If editorial explicitly requests audio (e.g. for client review cuts), deliver audio as a separate file alongside the video — never embedded in the container:

  • Preferred: WAV (48kHz, 24-bit, stereo)
  • Acceptable: AAC (48kHz, 256kbps stereo) for screener-only use
Never mux audio into a video delivery. Downstream tools in the finishing pipeline assume MOS VFX elements — embedded audio causes sync issues in editorial and automated QC failures.
