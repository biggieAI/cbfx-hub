Shot Naming Pattern

{SHOW}_{SEQ}_{SHOT}_{TASK}_{VERSION}

Example: PROJ_010_0100_COMP_v001

{SHOW}
4-character uppercase show code, assigned at project kickoff (e.g. PROJ).
{SEQ}
3-digit zero-padded sequence number (e.g. 010, 020).
{SHOT}
4-digit zero-padded shot number within the sequence (e.g. 0100).
{TASK}
Uppercase task abbreviation: COMP, FX, CG, ROTO, PAINT, GRADE.
{VERSION}
Lowercase v + 3-digit zero-padded version number (e.g. v001, v012).

File Sequences & Frame Padding

Always use %04d for frame padding in sequence notation. Never use single or double-digit padding — pipeline tools assume 4-digit padding uniformly.

PROJ_010_0100_COMP_v001.%04d.exr

# Frame range example (1001–1100):
PROJ_010_0100_COMP_v001.1001.exr
PROJ_010_0100_COMP_v001.1002.exr
...
PROJ_010_0100_COMP_v001.1100.exr

Nuke: use # notation in Write nodes — the system maps this to 4-digit %04d. Confirm padding in Read node info panel before rendering.

NAS Path Structure

Y:\{SHOW}\
  {SEQ}\
    {SHOT}\
      COMP\
        renders\       ← output EXR sequences go here
        scripts\       ← Nuke scripts (.nk)
      FX\
        renders\
        scripts\
      CG\
        renders\
        scripts\
      ROTO\
        renders\
        scripts\
      PAINT\
        renders\
        scripts\
      GRADE\
        renders\
        scripts\
  _DELIVERY\           ← client deliveries only (managed by pipeline)
⚠ Never write outputs directly to the root show folder or to _DELIVERY — pipeline scripts manage delivery packaging. Always write to the task-appropriate renders\ subfolder.

Do / Don't Quick Reference

Convention Allowed
Spaces in filenamesNo
Special characters in filenames (! @ # $ % ^ &)No
Lowercase show code (e.g. proj instead of PROJ)No
Short version suffix (e.g. v1 or v01 instead of v001)No
Single-digit frame paddingNo
Uppercase task codes (COMP, FX, CG, ROTO, PAINT, GRADE)Yes
Date in delivery filename (YYYYMMDD format)Yes
Underscores as token separatorsYes

Delivery Filename Pattern

{CLIENT}_{SHOW}_{SHOT}_{VERSION}_DLVR_{YYYYMMDD}

Example: STUDIOX_PROJ_010_0100_v003_DLVR_20260520

The _DLVR_ suffix flags the file as a finalized client delivery — never use this suffix on internal review renders. The date reflects the day the delivery is packaged, not the render date.

ShotGrid Field Mapping

ShotGrid Field Naming Token Notes
Shot Code SHOW_SEQ_SHOT e.g. PROJ_010_0100 — no task or version
Version Name Full filename stem e.g. PROJ_010_0100_COMP_v001 — no extension
Task TASK abbreviation Must match exactly: COMP, FX, CG, ROTO, PAINT, GRADE
Sequence SEQ (3-digit) e.g. 010 — must be zero-padded
Published File Path Full NAS path with %04d Relative to Y:\ root — confirm mapping with pipeline
